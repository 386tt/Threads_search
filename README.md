# Threads 精确搜索工具

这是一个基于 HTML + JavaScript 的超级()轻量级 Threads 搜索辅助页面，帮助你更高效地在 Threads 相关内容中进行精准检索(没办法，结合这个还是一坨)，并结合 Google/Threads 官方搜索入口进行补充查询。

## 功能概览

- 支持搜索类型切换：Google、Threads、两个都搜
- 支持常用搜索语法：
  - 精确短语：`"keyword"`
  - 排除词：`-word`
  - OR 逻辑：`keyword1 OR keyword2`
  - 用户筛选：`@username` / `site:threads.net`
  - 时间筛选：`after:YYYY-MM-DD`
- 支持最近 7 天 / 30 天时间过滤
- 支持搜索历史保存与快速重复搜索
- 提供个人资料页，直接访问用户 Threads 主页
- 支持在用户资料中按关键词搜索
- 自动保存本地数据（浏览器本地存储）

## 文件说明

- `threads_search.html`：主页面文件，包含全部 UI、交互和搜索逻辑

## 使用方法

1. 在浏览器中打开 `threads_search.html`
2. 在搜索框中输入关键词或帖子内容
3. 选择搜索模式：
   - Google
   - Threads
   - 两个都搜
4. 可使用高级语法或快捷按钮快速构造查询
5. 点击搜索按钮即可打开 Google/Threads 的搜索结果页面

## 适用场景

- 通过关键词查找 Threads 上的帖子
- 搜索指定用户发布的内容
- 限定时间范围查找最近内容
- 结合 Google 搜索覆盖 Threads 官方搜索的局限性

## 重要提示

- Threads 官方搜索功能存在限制，建议优先结合 Google 搜索使用
- 直接访问用户资料是查找历史帖子最可靠的方法
- 如果想搜某个用户的旧帖，最稳妥的方式是先访问其个人资料，再在资料中进行关键词搜索

## 运行方式

这个项目不需要安装依赖，也不需要启动本地服务器。直接双击打开 HTML 文件即可使用。

## 说明

该工具适合用于个人检索、研究、内容回溯等场景，目标是提升 Threads 内容搜索效率，特别适合处理“关键词不容易命中”或“官方搜索有限”的情况。

---

由于Threads本身对旧文章的归档与检索就特别差，导致这个工具实际上没有什么太大作用。。。。
